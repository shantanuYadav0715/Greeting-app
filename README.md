# Greeting App

A lightweight interactive web application that generates personalized greetings with animated visual effects.

## Features
- Personalized greeting input
- Responsive UI
- Canvas-based visual effects
- Multiple greeting animations
- Accessible live greeting output
- Deployed demo

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API

## Live Demo
https://greeting-app-puce.vercel.app

## Run Locally
Open index.html in a browser, or serve the project with any static HTTP server.

- Canvas animations
